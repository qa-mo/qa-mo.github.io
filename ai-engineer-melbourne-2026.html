Main Themes from the Conference

1. Production Reality, Not Prototypes

Companies shared real production experiences - what worked, what failed, and actual costs. Examples: $1.5M/year productivity gains at SEEK, systems handling 250M+ users at Canva, and 10% engagement lifts at REA Group.

2. Security Through Smart Design

You can't just "block bad things" with AI systems. Instead, design systems that stay safe even when things go wrong. Think seatbelts, not just careful driving.

3. Memory is Critical

The difference between a demo and a production AI agent is whether it can remember what it's doing across hours or days - like the difference between a sticky note and a proper filing system.

4. Testing is Everything

Having good ways to measure if your AI is working correctly is more important than tweaking prompts. It's like having a thermometer vs. just guessing if food is cooked.

5. Cost Matters

AI costs directly affect what features you can build. It's like choosing between express shipping or regular - sometimes the cheaper option is fine.

Day 1 June 3, 2026 - Software Engineering Track

10 sessions from the Software Engineering track with full transcripts:

1. Observability & LLM Evaluation at Scale ✓ Full Transcript

Speaker: Sergei
Covered trace sampling, enrichment, and a layered evaluation approach using offline evals, shadow runs, LLM-as-judge, human QA, and live metrics for assessing AI system quality.

2. Fail Fast, Fix Faster: Why Faster Models Can Beat Smarter Ones ✓ Full Transcript

Speaker: Andrew Fisher (VP Digital Science, Tetratherix)
Explored how faster model iteration loops outperform static, high-capability approaches. Demonstrated that "fast-loop theory" with rapid feedback cycles produces better outcomes than relying solely on advanced models.

3. Building Interactives at Scale Using AI ✓ Full Transcript

Speaker: Stile representative
Discussed automating interactive educational content creation through bootstrap, improvement workflows, and Armchair General build coordination to deploy 250+ simulations.

4. Coding Is 15% of Engineering Work ✓ Full Transcript

Speaker: Je Cornwall
Analyzed developer time allocation, showing coding represents only 15% of engineering effort. Demonstrated how identifying true system bottlenecks—not just coding speed—determines where AI tools create measurable impact.

5. From Zero to Production: Shipping LLM Products Safely ✓ Full Transcript

Speaker: Michael Zhang (Principal AI Engineer, MYOB)
Outlined seven learnings for deploying production LLM systems: narrow scope first, progressive rollout, security-as-architecture, read-only defaults, legacy system integration, AI-assisted tooling, and reversible-by-default decisions.

6. Multi-Armed Bandits: The Scientific Shotgun for Evals ✓ Full Transcript

Speaker: Ron Au
Introduced bandit algorithms (epsilon-greedy, Thompson sampling) for efficient online evaluation, showing how adaptive allocation outperforms fixed A/B testing when exploring multiple model or prompt variations.

7. Agents Don't Like Your APIs ✓ Full Transcript

Speaker: Mike Chambers (AI Specialist & Senior Developer Advocate, AWS)
Demonstrated how agent-oriented API design differs fundamentally from human-facing interfaces. Presented four principles: outcomes over operations, flattened arguments, contextual error messages, and ruthless tool curation.

8. Infrastructure as Context: Building AI Control Planes ✓ Full Transcript

Speaker: Jay Wren (StackQL)
Proposed treating infrastructure as queryable data layers via StackQL/Steampipe, with policy gates (Cedar), semantic tool filtering, and OpenTelemetry tracing to safely govern autonomous agents.

9. Agentic Healing in Production ✓ Full Transcript

Speaker: Jack McNicol (Founding Engineer, SuperIT)
Outlined workflows for autonomous issue resolution: agentic health checks, flow state optimization, "back pressure" testing, and event-driven agent scheduling for code debt and architecture audits.

10. Scalable Support for 260M+ MAU ✓ Full Transcript

Speaker: Canva representatives
Detailed layered evaluation architecture for customer support AI: offline evals → shadow runs → LLM-as-judge → human QA → live metrics, with async PII redaction and trace enrichment for production safety.

Day 2 June 4, 2026 - Sessions

4 sessions with full transcripts from Day 2:

1. Growing on Purpose — The Work That Makes You ✓ Full Transcript

Speaker: Jeremy Howard (Answer.AI)
23:04-23:47 UTC (Day 1 evening / Day 2 early morning)
Explores psychological research on human flourishing, drawing from Self-Determination Theory. Contrasts eudaimonia (actualizing capabilities) with hedonia (frictionless pleasure). Warns against "junk flow"—the seductive but unproductive state in AI-assisted coding where developers feel productive without substantive output. Advocates for human creativity amplification rather than replacement, referencing Douglas Engelbart's vision of intelligence augmentation.

2. Quality Evaluation in AI Systems ✓ Full Transcript

Speaker: Not identified
Focuses on establishing consistent quality metrics across AI systems through traces, layered evaluations (combining LLM judges, human QA, and live metrics), and democratizing evaluation responsibilities across product, QA, and engineering teams. Key theme: "traces become the language we speak."

3. Distributed LLM Inference ✓ Full Transcript

Speaker: Mic Neale
Presents mesh-LLM, a peer-to-peer inference system enabling 480B-parameter models on commodity hardware via pipeline parallelism, speculation, and mixture-of-agents approaches. Emphasizes edge computing's 2-3x greater inference capacity than datacenters.

4. Long-Horizon AI Tasks ✓ Full Transcript

Speaker: Zixuan Li (Z.ai/GLM-5.1)
Discusses AI capabilities for extended autonomous reasoning (8+ hours), categorizing tasks as subjective (visual polish, completeness) or objective (measurable benchmarks). Highlights human interventions: checklists, verification gates, and replanning prompts.

What is AgentPass?

This conference had a unique feature: AI agents could "attend" sessions on behalf of humans. The agents could:

  • Listen to live captions from all sessions
  • Monitor multiple rooms at the same time
  • Alert you when topics you care about come up
  • Summarize sessions automatically
  • Capture code snippets and tools mentioned

This is why I was able to capture detailed notes from 4 sessions - the conference made everything accessible through machine-readable captions and APIs.
